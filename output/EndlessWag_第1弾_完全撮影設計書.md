「海のゴミで、犬のタグを作ってみた」
縦型 9:16 / TikTok・Reels / 目標尺：75秒

---

## ■ 撮影前の基本設定

**スマホ設定**
- 縦持ち固定（絶対に横にしない）
- 解像度：4K or 最高画質
- フレームレート：30fps（スローにしたい場合は60fps）
- グリッド線：ON（水平・垂直の基準にする）
- ロック：露出・フォーカスをタップしてロック（AE/AFロック）

**光の条件（最重要）**
- **撮影は必ず午前8〜10時 or 午後15〜17時**
- 晴れた日の真昼は絶対NG（影が汚い、白飛びする）
- 曇りの日は意外と均一でいい光になる

**固定方法**
- 三脚があれば使う
- なければ石・砂・段差にスマホを置いて固定
- 手持ちの場合は脇を締めて両手でしっかり持つ

### 【BLOCK C：話す（問題提起）】 20〜35秒

---

**SHOT 08｜海を背景に話す（トーキングヘッド）**

```
📐 画角：バストアップ（胸から上）
📱 向き：縦持ち・目線の高さ
🎯 フレーム：顔が上1/2、海・空が下1/2
🕐 尺：10〜15秒
🎬 動き：完全固定
```

撮り方：
- 自撮りモードで撮る（または誰かに持ってもらう）
- 海を背に立つ
- 目線はカメラレンズを見る（画面じゃなくレンズ）
- 太陽を顔の斜め前方向に置く（逆光NG）

フレームイメージ：
```
┌─────────────────┐
│  空・雲         │
│  海の水平線     │
│                 │
│  ← 顔（中央）→ │
│  胸・肩         │
└─────────────────┘
```

セリフ（そのまま話す）：
```
「銚子の海、来るたびにゴミが落ちてるんですよ。
 捨てようかなって思ったんですけど、
 なんかもったいなくて。
 
 犬のグッズ作ってるんで、
 これタグにできるんじゃないかなって思って」
```

ポイント：
- 噛んでもOK、止まってもOK
- 「思って」で少し止まるくらいの間がちょうどいい
- 笑わなくていい。真剣な顔でOK

## ■ カット割り・編集設計

```
SHOT01（2s）→ SHOT02 テキスト → SHOT03（2s）
→ SHOT04（3s）→ SHOT05×3（各0.7s）→ SHOT06（3s）→ SHOT07（2s）
→ SHOT08（12s）
→ SHOT09（1.5s）→ SHOT10（2s）→ SHOT11（2s）→ SHOT12（2s）→ SHOT13（2s）
→ SHOT14（3s）→ SHOT15（2s）→ SHOT16（2s）
→ SHOT17（3s）→ SHOT18+テキスト（5s）
```

**トランジション（繋ぎ方）**
- 基本：カット（ぶった切り）でOK。凝ったエフェクトいらない
- SHOT07 → SHOT08 だけ：0.5秒の暗転 or 波音フェードアウト
- SHOT13 → SHOT14 だけ：0.3秒の白飛ば し（感情の切り替え）

## ■ 音の設計

| ブロック | 音 |
|---------|-----|
| SHOT01〜07 | 波音のみ（BGMなし） |
| SHOT08 | 自分の声のみ（BGMなし） |
| SHOT09〜13 | BGMをフェードイン（lo-fiインスト系） |
| SHOT14〜16 | BGM継続・少し音量上げる |
| SHOT17〜19 | BGMをフェードアウト・波音に戻す |

**BGMの探し方**
- TikTok音源：「lo-fi」「acoustic」「chill」で検索
- YouTubeオーディオライブラリ：無料・著作権フリー
- Epidemic Sound（有料・月額だが品質高い）

## ■ 絶対やってはいけないこと

- ❌ ズーム機能を使う（画質が落ちる。体で近づく）
- ❌ 逆光で人物を撮る（シルエットになる）
- ❌ 手持ちで歩きながらの長回し（ブレて見づらい）
- ❌ 真昼の直射日光（白飛び・影がきつい）
- ❌ 凝ったエフェクトを多用（内容が安っぽく見える）
- ❌ BGMを最初からずっと流す（飽きる・引きにくい）

## ■ 完成形のイメージ（編集後）

```
[波音] 砂のプラアップ → テキスト「これ、何になると思う？」
[波音] 海岸全景 → 足元 → プラ×3カット → 拾う → 袋
[無音→声] 「銚子の海、来るたびにゴミが落ちてる…」
[BGM in] 洗う → 削る → 穴開け → 完成タグ → ビフォーアフター
[BGM up] タグ付け → 犬の顔 → タグアップ
[BGM fade] 後ろ姿・海 → テキスト「捨てられるはずだったものが、
                            誰かの宝物になった。Endless Wag」
```
