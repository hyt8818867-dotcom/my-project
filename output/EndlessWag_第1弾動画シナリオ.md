# Endless Wag 第1弾動画 構成・シナリオ
対象: TikTok / Instagram Reels（縦型・60〜90秒）

---

## ■ コンセプト

**タイトル案**
「海のゴミで、犬のタグを作ってみた」

**一行メッセージ**
捨てられるはずだったものが、誰かの宝物になる。

---

## ■ 全体構成（60〜90秒）

| 秒数 | シーン | 内容 |
|------|--------|------|
| 0〜3秒 | **フック** | 海岸に落ちてるプラスチックのアップ。テキスト「これ、何になると思う？」 |
| 3〜15秒 | **現場** | 銚子の海岸でプラを拾う様子。波音。無言でOK |
| 15〜30秒 | **問題提起** | 顔出し or ナレーション「銚子の海、来るたびにゴミがある。でも捨てるのもなんか違うと思って」 |
| 30〜50秒 | **行動** | プラを洗う → 削る/加工する → タグの形にする過程（タイムラプスOK） |
| 50〜60秒 | **完成** | 犬に付けた瞬間。犬のアップ |
| 60〜75秒 | **締め** | 「捨てられるはずだったものが、誰かの宝物になった。これがEndless Wag」テキスト |

---

## ■ シーン別シナリオ

---

### SCENE 1：フック（0〜3秒）
**映像**
- 海岸に落ちているプラスチックのアップ（ペットボトルのキャップ、漁具の破片など）
- カメラが拾い上げる動き

**テキスト（画面上）**
```
これ、何になると思う？
```

**ポイント**
- 最初の1秒で止まらせる
- BGMはなし or 波音のみ
- 編集でテキストをポンと出す

---

### SCENE 2：現場（3〜15秒）
**映像**
- 銚子の海岸全景（広角）
- しゃがんでプラを拾う手元のアップ
- 集めたプラをビニール袋に入れる様子

**ナレーション（声 or テキスト）**
```
銚子の海、来るたびにゴミが落ちてる。
```

**撮影メモ**
- 逆光・夕方だと映えるが朝でもOK
- 海と空が映るアングルを意識
- 「一人で来た感」を出す（誰かに撮ってもらう場合は映さない）

---

### SCENE 3：問題提起（15〜30秒）
**映像**
- 顔出しで海を背景に話す（または手元・海のカットにナレーション）

**セリフ**
```
これ、捨てようかなって思ったんですよ。
でもなんかもったいなくて。

うちで犬のグッズを作ってるんですけど、
「これ、タグにできるんじゃないかな」って思って。
```

**テキスト補助**（セリフと一緒に出す）
```
海洋プラスチック → 犬のタグへ
```

**ポイント**
- 完璧に話さなくていい。「思って」で止まるくらいが自然でいい
- 顔出しが難しければ手元 + ナレーションでも十分

---

### SCENE 4：制作過程（30〜50秒）
**映像（タイムラプス or カット割り）**
1. プラを水洗い
2. ヤスリで形を整える
3. ドリルで穴を開ける（or キリで）
4. 文字を刻印 or ペンで書く
5. 金具を付ける
6. 完成したタグを手に持つ

**BGM**
- ここだけBGMを入れるとテンポが出る
- lo-fi系 or インスト系

**テキスト（各カットに）**
```
洗う → 削る → 穴を開ける → 完成
```

**撮影メモ**
- 手元のアップだけで十分
- 完成度より「作ってる感」を大事にする
- 失敗してもそのまま使っていい

---

### SCENE 5：完成・犬（50〜60秒）
**映像**
- タグを犬の首輪に付ける手元
- 犬の顔・首元のアップ
- 犬がこちらを見る瞬間

**テキスト**
```
海のゴミが、こうなった。
```

**ポイント**
- ここが一番エモい
- BGMを少し上げる
- 犬がじっとしてなくてOK、それも自然でいい

---

### SCENE 6：締め（60〜75秒）
**映像**
- 海岸の遠景 or 犬と一緒にいる後ろ姿

**テキスト（ゆっくり表示）**
```
捨てられるはずだったものが、
誰かの宝物になった。

Endless Wag
```

**最後のカット（任意）**
```
Gives Values合同会社
一人一人が、レアカード。
```

## ■ 撮影チェックリスト

**持ち物**
- [ ] スマホ（縦撮り固定）
- [ ] ビニール袋（プラ収集用）
- [ ] ヤスリ・キリ・金具（加工道具）
- [ ] 犬

**撮影場所**
- 銚子の海岸（外川漁港近く or 君ヶ浜あたりが映える）

**撮るべきカット一覧**
- [ ] 海岸全景（広角）
- [ ] プラが落ちてるアップ
- [ ] 拾う手元
- [ ] 話してる自分（or 手元）
- [ ] 洗う・加工する各工程
- [ ] 完成したタグ
- [ ] 犬に付ける瞬間
- [ ] 犬のアップ
- [ ] 海を背景にした後ろ姿

**撮影時間の目安**
- 海岸ロケ：30〜45分
- 加工シーン：15〜30分
- 犬シーン：10分
- 合計：1〜1.5時間あればOK
