## ■ ステージ1：どこで知る

**Endless Wagを「知る」きっかけ**

| 流入元 | 具体的な場面 | 強さ |
|--------|-----------|------|
| TikTok おすすめ欄 | 「海のゴミで犬のタグを作ってみた」が流れてくる | ★★★（最重要） |
| Instagram Reels | 犬アカウントのフォロワーに拡散される | ★★☆ |
| 犬好きコミュニティ | 「これいいね」とシェア・口コミが回る | ★★☆ |
| ハッシュタグ検索 | #アップサイクル #犬のいる生活 #ハンドメイド | ★★☆ |
| 銚子・千葉ローカル | 地元イベント・マルシェで実物を見て後でSNS検索 | ★☆☆ |
| YouTube（将来） | 「海洋プラスチック 犬 タグ」検索流入 | ★☆☆（後から） |

**最初の1秒で止まる理由（フック設計）**
- 「海に落ちてるゴミ」という意外性
- 「これ、何になると思う？」という問いかけ
- 「犬」という普遍的な共感軸
- 「銚子」という実在する場所のリアリティ

## ■ ステージ2：どこからアクセス

**視聴者が「使う」場面・環境**

| 環境 | 具体的な場面 | 設計上の意味 |
|------|-----------|------------|
| 犬の散歩中 | 片手でスマホ・イヤホンなし | 音がなくても伝わる字幕が必須 |
| 通勤・移動中 | 電車・バス・縦持ちスマホ | 縦型9:16・60〜90秒がベスト |
| 夜のながら見 | ソファ・スマホ・リラックス中 | BGMと映像の世界観が刺さる |
| 犬好きコミュニティの中 | TikTok・Instagramをぼーっと見てる | 「犬が出てくる瞬間」で止まる |
| 検索して来た人 | 「アップサイクル 犬」などで能動的に探す | 概要欄・キャプションが決め手 |

**スマホ最適化の設計チェック**
- [ ] 縦型（9:16）で全部収まる
- [ ] 字幕があれば音なしでも内容が分かる
- [ ] 最初の1〜2秒でジャンルが分かる
- [ ] 60〜90秒で完結する

## ■ ステージ3：どうやって使う（視聴体験）

**受け手がコンテンツを「体験」するときに起きること**

### 感情の流れ（75秒間）

```
0〜3秒：「なにこれ？」（疑問・停止）
    ↓ 海に落ちてるプラのアップ → テキスト「これ、何になると思う？」
3〜15秒：「あ、銚子の海か」（場所の認識・共感）
    ↓ 波の音・海岸の景色・拾う手元
15〜30秒：「なるほどそういうことか」（意図の理解）
    ↓ 「捨てようかと思ったけど、タグにできるんじゃないか」
30〜50秒：「おお、ちゃんと作ってる」（信頼・驚き）
    ↓ 洗う→削る→穴を開けるプロセス
50〜60秒：「かわいい！！」（感情ピーク）
    ↓ 犬に付ける瞬間・犬の顔のアップ
60〜75秒：「なんかいい話だな」（余韻・共感・拡散欲求）
    ↓ 後ろ姿と犬・「捨てられるはずだったものが宝物になった」
```

### コンテンツが持つべき「密度の設計」

| 要素 | クウキデザインの基準 | Endless Wagへの適用 |
|------|-------------|-----------------|
| 情報の密度 | 多すぎず・少なすぎず | 1動画1メッセージ（「ゴミ→宝物」だけ） |
| 本質メッセージ | 1つに絞る | 「捨てられるはずだったものが、誰かの宝物になる」 |
| 安心できる質 | 見た目・声・場所がちゃんとしてる | 海・太陽の光・犬・手作り感が「本物感」を作る |
| 経験浅くても分かる | 専門知識なしで理解できる | プラ拾い→作る→犬に付ける。説明なしで分かる |
| 失敗もOK | 完璧じゃない方が親近感 | 手がぎこちなくてもOK・犬が動いてもOK |

## ■ ステージ4：結果

### 受け手に起きること（感情・行動）

```
【すぐ】
・最後まで見た（TikTokのアルゴリズムが伸びる）
・いいねを押した
・「かわいい」「いい話」「銚子行きたい」とコメントした
・保存した（「また見たい」）
・シェアした（「これ見て」）

【少し後】
・アカウントをフォローした（「次も見たい」）
・プロフィールを見に行った
・BASEのリンクを踏んだ

【さらに後（ファン化）】
・タグを買った
・「銚子のゴミで作られたタグ」という物語ごと購入した
・「犬にも地球にも良いもの」という世界観に共鳴した
・第2弾・第3弾も見た
・「一緒に何かしたい」と思い始めた（コアファン化）
```

### 作り手（はやとさん）に返ってくるもの

| 指標 | 意味 |
|------|------|
| 再生数・完視聴率 | コンテンツの質を測る |
| フォロワー増加 | ブランドの信頼蓄積 |
| コメント内容 | 受け手が何に反応したかのリサーチ |
| BASE流入・購買 | コンテンツが収益につながる証拠 |
| 「銚子行きたい」「ゴミ拾い行きたい」 | コミュニティ化のサイン |

## ■ 4ステージを使ったコンテンツ改善チェックリスト

**第1弾動画を出す前に確認**

### ステージ1（知る）チェック
- [ ] タイトル/テキストに「問いかけ」が入ってるか
- [ ] ハッシュタグが犬・アップサイクル・銚子の3軸カバーしてるか
- [ ] 最初の1〜2秒で止まる理由があるか

### ステージ2（アクセス）チェック
- [ ] 縦型9:16で撮れてるか
- [ ] 音なしでも字幕で分かるか
- [ ] 90秒以内に収まってるか

### ステージ3（使う）チェック
- [ ] 感情の流れが「疑問→共感→驚き→感動→余韻」になってるか
- [ ] 1本のメッセージが最初から最後まで一貫してるか
- [ ] 犬が出てくる「感情ピーク」がちゃんとあるか

### ステージ4（結果）チェック
- [ ] 見た後に「買える場所」がプロフィールに書いてあるか
- [ ] 次のコンテンツへの導線があるか（第2弾の予告など）
- [ ] コメントを返す体制があるか（初期は全件返す）
