### ◆ 楽天フォーム設定メモ

```
【推奨設定】
・料金形式: 曜日別（曜日/休前日・祝前日）を選択
  → 日〜木 = Aランク入力
  → 金・土(休前日) = Bランク入力
  → 祝前日 = Cランク入力
  
・繁忙期（GW・お盆・年末年始）= カレンダーで日付指定して上書き入力

・「楽天トラベル 1人あたり」「通常料金 1人あたり」= 同じ値を入力でOK

・子供料金設定:
  - 小学生: 大人と同じ
  - 幼児: なし（布団なし・食事なし）

・5名以上の注意: 5名÷の1人あたり金額を入力すると、
  6〜8名が来た場合は合計が増える（例: 間Aランク、8名=¥60,800）
  → 一棟貸しとして許容範囲。大人数ほど割高になる仕組みは一般的。
```
