## 事前に準備するもの（3宿共通）

### 施設情報
- [ ] 施設名・正式住所・電話番号
- [ ] チェックイン／チェックアウト時間
- [ ] 定員人数・部屋数
- [ ] 設備リスト（Wi-Fi・駐車場・キッチン・バスルーム等）
- [ ] アメニティリスト（タオル・歯ブラシ・シャンプー等）
- [ ] 宿泊施設種別（民泊届出番号 or 旅館業許可番号）

### 写真（最重要・予約率に直結）
- [ ] 外観（昼間・明るい）
- [ ] 玄関・エントランス
- [ ] リビング・ダイニング
- [ ] 寝室（ベッドメイク済みの状態）
- [ ] バスルーム・トイレ・洗面台
- [ ] キッチン
- [ ] 近隣（海・港・銚子の風景）
> 最低10枚・自然光・横向き推奨

### 料金設定（初期値）
- [ ] 平日通常料金
- [ ] 土日・祝前日料金
- [ ] GW・お盆・年末年始料金（×1.5）

## STEP1: じゃらんnet への登録

### 手順
1. 「じゃらんnet 宿・ホテル掲載申し込み」で検索
2. 「宿・ホテル掲載のご案内」ページから申し込みフォームへ
3. 施設情報・担当者情報を入力して送信
4. 担当者から連絡が来る（1〜3営業日）
5. 審査通過後、管理画面（じゃらんパートナーネット）が開通

### 民泊（舫）の注意点
- 申し込み時に「住宅宿泊事業」を選択
- 届出番号の入力が必須
- 審査に通常より時間がかかる場合あり

### Airhostとの連携
- じゃらんはAirhostとAPI連携可能
- 管理画面開通後、AirhostのOTA連携設定からじゃらんを選択
- カレンダー同期・料金同期を設定

---

## STEP2: 楽天トラベル への登録

### 手順
1. 「楽天トラベル 掲載申し込み」で検索
2. 「宿泊施設掲載のご案内」から申し込み
3. 旅館業 or 民泊を選択して情報入力
4. 審査・契約（1〜2週間程度）
5. 管理画面（R-Travel Manager）開通

### Airhostとの連携
- 楽天トラベルはAirhostとAPI連携可能
- 開通後にAirhost側で連携設定

---

## STEP3: Yahoo!トラベル への登録

### 手順
- Yahoo!トラベルはじゃらんnet経由で掲載される仕組み
- **じゃらんに掲載されれば、Yahoo!トラベルにも自動掲載される場合が多い**
- じゃらん登録時に「Yahoo!トラベル連携」の有無を確認

---

## STEP4: Airhost（チャンネルマネージャー）設定

### 目的
- 全OTAのカレンダーを一元管理 → ダブルブッキング防止
- 料金変更を一括反映

### 設定手順
1. Airhostにログイン
2. 「物件管理」→ 各宿を追加登録
3. 「OTA連携」から各サイトを接続
   - Booking.com: すでに連携済み → 確認のみ
   - Airbnb: すでに連携済み → 確認のみ
   - じゃらん: 管理画面開通後に設定
   - 楽天: 管理画面開通後に設定
4. カレンダー同期テスト（どこかで仮予約して反映されるか確認）
5. 最低宿泊数・キャンセルポリシーを統一設定
