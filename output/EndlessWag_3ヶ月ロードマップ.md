## ■ リサーチから分かったこと（要点だけ）

### アルゴリズムの真実（2026年最新）
- **最初の0.4秒**で視聴者はスワイプするか決める
- **3秒時点で60%残ってる動画は、そうでない動画の4倍リーチが出る**
- 重要指標の順番：完視聴率 > リピート再生 > 保存 > コメント > シェア > いいね
- 「いいね」より**「保存」**が強い（2026年から変化）
- 投稿後**1〜2時間の初動**でおすすめに乗るか決まる

### シュナウザーはブルーオーシャン
- 世界最大のシュナウザーTikTokアカウント（Winston Schnauzer）でも**7.4万フォロワー**
- 柴犬は620万、トイプードルは990万いるのに、シュナウザーの大型アカウントがない
- **「シュナウザーといえばミシェル」のポジションは今なら取れる**

### 犬動画は最強ジャンルの1つ
- TikTokユーザーの**70%以上が毎週ペットコンテンツに接触**
- 犬はペット市場の**50%のシェア**（最大カテゴリー）
- 動物は本能的に注意を引くため、完視聴率が高くなりやすい

### 収益化マイルストーン
| フォロワー | 解放される機能 |
|-----------|-------------|
| 1,000 | **LIVEギフト受取**・TikTok Shop |
| 10,000 | **Creator Rewards Program**・企業マッチング |
| 100,000 | 大型PR案件（1投稿5万〜75万円） |

### LIVE収益の現実値
- 30分配信で7,500〜75,000円（フォロワー規模による）
- フォロワー2万〜10万で月7.5万〜45万円
- TikTokの手数料は50〜70%（手元に30〜50%）

## ■ 3ヶ月ロードマップ

### Month 1：7月（317→1,000フォロワー）
**テーマ：バズ動画の型をパクって毎日投稿**

#### やること
| 項目 | 内容 |
|------|------|
| 投稿頻度 | **毎日1本**（19:00〜21:00に固定） |
| 動画の長さ | **7〜15秒**（完視聴率を最大化） |
| コンテンツの型 | バズってる犬動画をパクる（後述） |
| ハッシュタグ | 5個固定（後述） |
| コメント回り | **毎日10件**、人気犬アカウントにコメント |
| コメント返信 | 自分の投稿への全コメントに返信 |
| YouTube Shorts | TikTok投稿の翌日に同じ動画をアップ |

#### バズる動画フォーマット（パクる型リスト）

**A. リアクション系（週3本）← 最優先**
```
パターン：おやつ/ご飯の気配→犬の反応
構成：テロップ（0秒）→ 仕掛け（1〜3秒）→ リアクション（3〜7秒）→ オチの顔
尺：7〜12秒
例：「ご飯ってわかった瞬間の犬」「おやつの袋の音で起きる速度」
```

**B. 頑固/拒否系（週2本）← シェアされやすい**
```
パターン：嫌なこと→全力拒否→おやつで秒解決
構成：テロップ（0秒）→ 拒否シーン（2〜5秒）→ おやつで解決（5〜8秒）
尺：8〜15秒
例：「100回呼んでも来ない犬、おやつで0.5秒」「絶対ケージに入らない犬」
```

**C. POV（犬の心の声）系（週1本）← フォローされやすい**
```
パターン：犬の行動にセリフテロップをつける
構成：シーン→犬の心の声テロップ→リアクション
尺：10〜15秒
例：「POV: 飼い主がご飯の準備を始めた音がした」
```

**D. あるある系（週1本）← 保存されやすい**
```
パターン：犬飼いあるあるをミシェルで再現
構成：テロップ「犬飼いにしかわからない〇〇」→ 実演
尺：10〜15秒
例：「犬飼いにしかわからない朝」「シュナウザーあるある」
```

#### テロップの鉄板パターン（これをローテーション）
| パターン | 例 |
|----------|---|
| 疑問・問いかけ | 「え、なんでそこで寝るの？」 |
| 衝撃・断定 | 「この犬、ご飯のためなら何でもする」 |
| POV（犬視点） | 「POV: おやつの袋が開いた音がした」 |
| あるある | 「シュナウザー飼いにしかわからないやつ」 |
| 数字 | 「0.5秒で来る犬」「100回呼んでも無視する犬」 |
| ギャップ | 「さっきまで寝てたのに」「全然聞かないのに」 |

#### ハッシュタグ（固定5個）
```
#シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok + 動画別タグ1つ
```

動画別タグ例：
- ご飯系 → #犬のごはん
- 頑固系 → #犬のしつけ
- 散歩系 → #犬の散歩
- おもしろ系 → #おもしろ犬

### Month 2：8月（1,000→3,000フォロワー）
**テーマ：LIVE開始＋シリーズ化＋コラボ**

#### やること
| 項目 | 内容 |
|------|------|
| 投稿頻度 | 毎日1本（継続） |
| **LIVE配信** | **週2回**（水・土 21:00〜 30分） |
| シリーズ化 | バズった型で3〜7話のミニシリーズ |
| コラボ | デュエット・スティッチを週1本 |
| コメント回り | 毎日10件（継続） |

#### LIVE配信のやり方
```
テーマ例：
・「ミシェルと夜のんびりLIVE」
・「ミシェルのご飯タイムLIVE」
・「ミシェルにお手教えるLIVE」

コツ：
・同じ曜日・時間に固定（ファンが習慣化する）
・コメントを読んで名前を呼ぶ
・「ミシェルに〇〇させてほしい」リクエストを受ける
・顔出しなしでOK（犬だけ映す）
```

#### マイクロシリーズ（2026年最強フォーマット）
```
例：「ミシェルにお手を覚えさせるまで」
Day 1 → Day 2 → Day 3 → ... → Day 7（完成）

仕組み：
・3〜7話で1ストーリー
・各話の最後に「次回へ続く」で引っ張る
・後半エピソードほど再生数が伸びる「複利効果」が発生
```

#### デュエット・スティッチ戦略
```
・人気犬動画をデュエット → ミシェルのリアクションを横に並べる
・人気動画をスティッチ → 冒頭を引用して「うちの場合」で続ける
・相手のフォロワーに発見される → フォロワー流入
```

## ■ バズ動画のパクり方（具体手順）

```
① TikTokアプリを開く
② 検索で「犬」「シュナウザー」「犬あるある」と入力
③ 「動画」タブで再生数が多いもの（10万以上）を探す
④ その動画の構成をメモする：
   - 最初のテロップは何？
   - 何秒の動画？
   - どういう展開？
   - オチは何？
⑤ その構成をそのままミシェルで再現する
⑥ テロップとサムネだけ自分の言葉に変える
```

**パクっていいもの：** 構成・展開・尺・テロップの型
**パクらないもの：** テロップの文言そのまま（自分の言葉に変える）
