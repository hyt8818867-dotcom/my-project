## ■ リサーチで見つけた「実際にバズってる」動画パターン

### パターン① ご飯リアクション系（最強カテゴリー）
- **Gordog Ramsay（犬名: Kora）**: 950万再生。ステーキを目の前に置く→犬が唇をペロペロ→食べた瞬間の表情。テキスト「Food Critic」
- **ビーガンフード犬**: 100万再生+21万いいね。POVテロップ「ご飯を乞うけどママはビーガン」→犬の困惑顔
- **ミシェルで再現可能**: おやつ/ご飯を目の前に→ソワソワ→お手連発→食べる瞬間。ミシェルの食いしん坊キャラど真ん中

### パターン② チャレンジ系（今バズってるトレンド）
- **Paws In（おてて集合）チャレンジ**: 人間が手を重ねる→犬が肉球を上に乗せる。シンプル＋再現しやすい
- **Boop（鼻ポチ）チャレンジ**: 犬の鼻を何回ポチポチ→何回目で怒るか。ゴールデンで50万いいね超え
- **Dog Freeze（無視）チャレンジ**: 犬を完全無視→犬がどうリアクションするか
- **ミシェルで再現可能**: 全部1人で撮れる。頑固キャラなので「何回ポチで怒るか」は最高にハマる

### パターン③ 大型バズの構造分析
- **@aguyandagolden "Knocked Out"**: 2.87億再生。飼い主のシンプルな日常行動→犬の予想外リアクション
- **@squashiebernedoodle**: 1200万再生で一気にインフルエンサー化。犬の個性が一発で伝わるワンシーン
- **@finniatureschnauzer**: シュナウザー最大級。「よーいドン」でダッシュする定番フォーマットを繰り返し投稿

### パターン④ 日本で強い型
- **柴犬コマリ（@shibakoma）**: 650万フォロワー。テレビ出演・写真集も。1本あたり数百万再生連発
- **犬アフレコ（心の声）**: 日本TikTok独自の強ジャンル。犬の行動にナレーション/テロップで心の声をつける

## ■ 法則（バズ動画に共通するルール）

| ルール | 理由 |
|--------|------|
| **行動ベース**（見た目の変化はNG） | 知らない犬の外見に他人は興味ない |
| **7〜12秒** | 完視聴率を最大化 → アルゴリズムが押す |
| **0秒目にテロップ** | 0.4秒でスワイプ判断される |
| **ギャップ構造（A→でも→B）** | 「100回呼んでも来ない→おやつで0.5秒」 |
| **繰り返し見たくなるオチ** | リピート再生 = アルゴリズム最重要指標の1つ |
| **トレンドチャレンジに乗る** | 既にバズってるフォーマット = 発見されやすい |

## ■ 7日間撮影プラン

### Day 1（火）: ご飯リアクション ← 最優先
**パクり元**: Gordog Ramsay（950万再生）
```
構成（8秒）:
0秒: テロップ「ご飯の準備始めた瞬間の犬」
1秒: キッチンでご飯を準備する手元（音だけ聞こえる）
3秒: カメラ切り替え → ミシェルがソワソワ＋お手連発
6秒: ご飯を置く → 食べる瞬間の顔アップ
8秒: 終了（食べてる途中で切る = もう一回見たくなる）

テロップ: 「ご飯の準備始めた瞬間の犬」
説明: ご飯の気配を察知する能力だけ異常に高い犬🐾
ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #犬のごはん
BGM: ショパン ノクターン（10%音量）+ 自然音100%
サムネ: ソワソワしてるミシェルの顔アップ + テロップ
```

### Day 2（水）: Boopチャレンジ ← トレンド乗り
**パクり元**: Golden Retriever Boop Challenge（50万いいね超）
```
構成（10秒）:
0秒: テロップ「鼻ポチ何回で怒るか検証」
1秒: ミシェルの鼻をポチ（1回目）→ 平気な顔
3秒: ポチポチ（3〜5回目）→ ちょっと嫌な顔
6秒: さらにポチ → 怒る or 逃げる or 噛もうとする
9秒: 最後のリアクション（オチの顔）で終了

テロップ: 「鼻ポチ何回で怒るか検証」
説明: 3回目までは許してくれた🐾
ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #boopchallenge
BGM: トレンド音源（TikTokで「boop challenge」検索して一番使われてるやつ）
サムネ: 鼻をポチされてる瞬間 + テロップ
```

### Day 3（木）: 名前 vs おやつ ← ギャップ系
**パクり元**: ミシェルの過去実績（「名前 < ご飯」915再生 = 現アカウント最高級）
```
構成（7秒）:
0秒: テロップ「100回呼んでも来ない犬」
1秒: 「ミシェル！ミシェル！」→ ガン無視（2〜3回繰り返し）
4秒: おやつの袋をガサッ
5秒: ダッシュで来る（0.5秒で到着）
7秒: 終了

テロップ: 「100回呼んでも来ない犬」
説明: おやつの袋の音には0.5秒で反応する犬🐾
ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #おもしろ犬
BGM: ショパン ノクターン（ガン無視シーンの静けさ → ダッシュのギャップ）
サムネ: ガン無視してるミシェル + テロップ
```

### Day 4（金）: Paws Inチャレンジ ← トレンド乗り
**パクり元**: Paws In / Hands In Challenge（2026年トレンド）
```
構成（8秒）:
0秒: テロップ「おてて集合チャレンジ」

   or 失敗 → 全然違うことする（頑固キャラ発動）

テロップ: 「おてて集合チャレンジ」
説明: 参加する気はあるっぽい🐾
ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #handsinchallenge
BGM: トレンド音源（TikTokで「hands in challenge」検索）
サムネ: 手の上にミシェルの肉球が乗ってる瞬間
```

### Day 5（土）: お手連発 ← ミシェル固有ネタ
**パクり元**: @finniatureschnauzerの「定番フォーマット繰り返し」戦略
```

4秒: 「何も持ってないよ」→ それでもお手連発

8秒: 終了

テロップ: 「最近お手すればもらえると思ってる犬」
説明: お手の安売りが止まらない🐾
ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #犬のしつけ

```

### Day 6（日）: 無視チャレンジ ← Freeze Challenge
**パクり元**: Dog Freeze Challenge（2026年トレンド）
```
構成（10秒）:
0秒: テロップ「犬を完全無視したらどうなるか」

3秒: ミシェルが近づいてくる → 顔を覗き込む
5秒: まだ無視 → ミシェルがさらにアクション（吠える/前足でつつく/膝に乗る）
8秒: 我慢できずにミシェルを見る → ミシェルの嬉しそうな顔
10秒: 終了

テロップ: 「犬を完全無視したらどうなるか」
説明: 30秒で限界きた🐾
ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #freezechallenge
BGM: トレンド音源
サムネ: ミシェルが顔を覗き込んでる瞬間
```

### Day 7（月）: POV犬の心の声 ← 日本TikTok独自の強ジャンル

テロップ: 上記の通り（心の声をテロップで表現）

ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #犬の気持ち

## ■ 撮影の鉄則

| ルール | 理由 |
|--------|------|
| **1ネタにつき3〜5テイク撮る** | ベストリアクションを選べる |
| **縦画面（9:16）で撮る** | TikTok/Shorts両方に使える |
| **自然光で撮る** | 暗い動画は離脱される |
| **CapCutで編集は5分以内** | テロップ + BGM + トリミングだけ |
| **TikTokに先にアップ** | 翌日にYouTube Shorts（ウォーターマークなし版） |
| **19:00〜21:00に投稿** | 日本のゴールデンタイム |

## ■ なぜこの7本で伸びるか

1. **3本がトレンドチャレンジ**（Boop/Paws In/Freeze）→ 検索・発見で見つかりやすい
2. **2本が食いしん坊キャラ**（ご飯リアクション/名前vsおやつ）→ ミシェルの個性確立
3. **1本がミシェル固有ネタ**（お手連発）→ 「この犬でしか見れない」を作る
4. **1本がPOV系**（心の声）→ 日本TikTokで最も保存されやすいジャンル
5. **全て7〜12秒**（完視聴率最大化）
6. **全て自宅で1人で撮れる**（スマホだけ）
7. **全て行動ベース**（見た目の変化は一切なし）

## ■ 7本中1本でもバズったら

そのフォーマットを**シリーズ化**する。

例: Boopチャレンジがバズった場合
- Day 1: 鼻ポチ何回で怒るか
- Day 2: 鼻ポチ → おやつで機嫌直るか
- Day 3: 鼻ポチ → 寝てる時にやったらどうなるか
- Day 4: 鼻ポチ → ロールにもやってみた

→ 後半ほど再生数が伸びる「複利効果」が発生する
