## ■ 法則（バズ動画に共通するルール）

| ルール | 理由 |
|--------|------|
| **行動ベース**（見た目の変化はNG） | 知らない犬の外見に他人は興味ない |
| **7〜12秒** | 完視聴率を最大化 → アルゴリズムが押す |
| **0秒目にテロップ** | 0.4秒でスワイプ判断される |
| **ギャップ構造（A→でも→B）** | 「100回呼んでも来ない→おやつで0.5秒」 |
| **繰り返し見たくなるオチ** | リピート再生 = アルゴリズム最重要指標の1つ |
| **トレンドチャレンジに乗る** | 既にバズってるフォーマット = 発見されやすい |

## ■ 7日間撮影プラン

### Day 1（火）: ご飯リアクション ← 最優先
**パクり元**: Gordog Ramsay（950万再生）
```
構成（8秒）:
0秒: テロップ「ご飯の準備始めた瞬間の犬」
1秒: キッチンでご飯を準備する手元（音だけ聞こえる）
3秒: カメラ切り替え → ミシェルがソワソワ＋お手連発
6秒: ご飯を置く → 食べる瞬間の顔アップ
8秒: 終了（食べてる途中で切る = もう一回見たくなる）

テロップ: 「ご飯の準備始めた瞬間の犬」
説明: ご飯の気配を察知する能力だけ異常に高い犬🐾
ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #犬のごはん
BGM: ショパン ノクターン（10%音量）+ 自然音100%
サムネ: ソワソワしてるミシェルの顔アップ + テロップ
```

### Day 2（水）: Boopチャレンジ ← トレンド乗り
**パクり元**: Golden Retriever Boop Challenge（50万いいね超）
```
構成（10秒）:
0秒: テロップ「鼻ポチ何回で怒るか検証」
1秒: ミシェルの鼻をポチ（1回目）→ 平気な顔
3秒: ポチポチ（3〜5回目）→ ちょっと嫌な顔
6秒: さらにポチ → 怒る or 逃げる or 噛もうとする
9秒: 最後のリアクション（オチの顔）で終了

テロップ: 「鼻ポチ何回で怒るか検証」
説明: 3回目までは許してくれた🐾
ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #boopchallenge
BGM: トレンド音源（TikTokで「boop challenge」検索して一番使われてるやつ）
サムネ: 鼻をポチされてる瞬間 + テロップ
```

## ■ 撮影の鉄則

| ルール | 理由 |
|--------|------|
| **1ネタにつき3〜5テイク撮る** | ベストリアクションを選べる |
| **縦画面（9:16）で撮る** | TikTok/Shorts両方に使える |
| **自然光で撮る** | 暗い動画は離脱される |
| **CapCutで編集は5分以内** | テロップ + BGM + トリミングだけ |
| **TikTokに先にアップ** | 翌日にYouTube Shorts（ウォーターマークなし版） |
| **19:00〜21:00に投稿** | 日本のゴールデンタイム |

## ■ なぜこの7本で伸びるか

1. **3本がトレンドチャレンジ**（Boop/Paws In/Freeze）→ 検索・発見で見つかりやすい
2. **2本が食いしん坊キャラ**（ご飯リアクション/名前vsおやつ）→ ミシェルの個性確立
3. **1本がミシェル固有ネタ**（お手連発）→ 「この犬でしか見れない」を作る
4. **1本がPOV系**（心の声）→ 日本TikTokで最も保存されやすいジャンル
5. **全て7〜12秒**（完視聴率最大化）
6. **全て自宅で1人で撮れる**（スマホだけ）
7. **全て行動ベース**（見た目の変化は一切なし）

## ■ 7本中1本でもバズったら

そのフォーマットを**シリーズ化**する。

例: Boopチャレンジがバズった場合
- Day 1: 鼻ポチ何回で怒るか
- Day 2: 鼻ポチ → おやつで機嫌直るか
- Day 3: 鼻ポチ → 寝てる時にやったらどうなるか
- Day 4: 鼻ポチ → ロールにもやってみた

→ 後半ほど再生数が伸びる「複利効果」が発生する

## ■ 中期目標: Finnegan方式「Go!」チャレンジ（2週間後〜）

@finniatureschnauzer の最大バズ動画（860万再生・10日間）を完全再現する。

**今日からトレーニング開始:**
1. 「マテ」を完璧にする（ミシェルは合図すれば待てるので、ほぼクリア）
2. 「Go!」で走り出すコマンドを覚えさせる（おやつで誘導→1〜2週間）
3. フェイク語（「Bow」「Grow」「Flow」「Blow」）に反応しないよう訓練

**撮影:**
- 場所: 自宅の廊下
- スマホ三脚固定、15秒
- テロップ: 「この犬、"Go"しか聞かない」
- フェイントの回数を増やすほどオチが面白くなる

**これがシリーズ化できたら、Finneganと同じ「シュナウザーといえばこれ」の型が完成する。**

## ■ もう1つの即撮り候補: What the Fluffチャレンジ

数億再生（TikTok+Instagram合算）のメガトレンド。

```
準備: スマホ三脚 + 大きめブランケット1枚
構成（10秒）:
0秒: テロップ「飼い主が消えたら犬はどうする？」
1秒: ミシェルの前に立つ
2秒: ブランケットを体の前に広げる（ミシェルの視界を遮る）
4秒: ブランケットを持ち上げた瞬間に横に逃げる
5秒: ブランケットが落ちる → 飼い主が消えてる
6秒: ミシェルの困惑・キョロキョロ・パニック
10秒: 終了

ハッシュタグ: #シュナウザー #犬あるある #犬のいる暮らし #dogsoftiktok #whatthefluff
```

シュナウザーは表情豊かなので「えっ？」の困惑顔が最高に映える。
