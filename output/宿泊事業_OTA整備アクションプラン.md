### 各OTA 登録に必要な情報（共通）

**施設基本情報**
- [ ] 施設名・住所・電話番号
- [ ] 宿泊施設種別（民泊 or 旅館業）
- [ ] チェックイン・チェックアウト時間
- [ ] 定員・部屋数
- [ ] 設備・アメニティ一覧

**写真（最重要）**
- [ ] 外観（昼・夜）
- [ ] 玄関・エントランス
- [ ] リビング・寝室・水回り
- [ ] 近隣の観光スポット・海・港
> ※写真の質で予約率が変わる。最低10枚・明るい自然光で撮影。

**料金設定**（→2位と連動）
- [ ] 通常期・繁忙期・GW料金を事前に決めて入力

---

### Airhost（チャンネルマネージャー）設定手順

1. Airhostにログイン → 「物件追加」で各宿を登録
2. 接続するOTAを選択（Booking/Airbnb/じゃらん/楽天/Yahoo）
3. 各OTAのAPI連携を設定（OTA側でAPI発行が必要）
4. カレンダー同期の確認（ダブルブッキング防止）
5. 最低宿泊数・前日キャンセル設定を統一

> **ポイント：じゃらん・楽天はAirhostと直接API連携可能。Yahoo!はじゃらんネット経由で連携できる場合あり。各OTAのパートナーサポートに確認。**

## 【2位】価格設定の見直し（今週中）

### GW前に上げるべき理由
- GW（4/26〜5/6）は銚子の最繁忙期のひとつ
- 今から適切に上げれば予約は入る
- 値上げしないままだと「安い宿」として埋まり、利益を取り逃がす

### 価格リサーチの手順

1. Booking.com / Airbnbで銚子市の一棟貸しを検索
2. 類似物件（定員・エリア・設備）の料金を確認
3. GW期間（4/26〜5/6）の料金も確認
4. 自宿の料金と比較 → 相場の8〜9割なら上げ余地あり

### 推奨価格設定の考え方

| 期間 | 設定の目安 |
|------|------|
| 平日通常期 | 競合平均と同水準 |
| 土日・祝前日 | 通常期 × 1.3〜1.5倍 |
| GW（4/26〜5/6） | 通常期 × 1.5〜2.0倍 |
| GW後〜5月末 | 通常期に戻す |
