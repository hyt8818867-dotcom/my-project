## ■ 各プラットフォームの役割

```
TikTok     = 発見（アルゴリズムが新規に届ける）
YouTube    = 蓄積（動画が何ヶ月も再生され続ける）
Instagram  = 販売（ショップ連携・DM・ブランド案件）
Threads    = 関係構築（テキストで人柄を出す → Instagramに流す）
```

**収益の流れ:**
```
TikTokでバズる → 「この犬かわいい」
    ↓
YouTube/Instagramもフォローされる
    ↓
Threadsで日常投稿 → 「飼い主も面白い」→ ファン化
    ↓
Instagramで Endless Wag の投稿が自然に目に入る
    ↓
購入 / LIVE投げ銭 / PR案件
```

## ■ 各プラットフォームの使い分け

### TikTok（メイン）
```
投稿: 毎日1本（7〜12秒のショート動画）
LIVE: 週2〜3回（1,000人達成後）
役割: 新規発見 → フォロワー獲得
収益: LIVEギフト + Creator Rewards
```

### YouTube Shorts
```
投稿: TikTokの翌日に同じ動画（ウォーターマークなし版）
将来: 月2本の長尺動画（3〜5分）を追加 → 広告RPM大幅UP
役割: 長期蓄積。TikTokは流れるがYouTubeは残る
収益: 広告収益（長尺追加後に本格化）
```

### Instagram
```
投稿: リール（TikTokと同じ動画）週3本 + ストーリーズ毎日
役割: 販売導線。プロフィールにBASEリンク → Endless Wag購入
収益: DM販売 + ショップ連携 + PR案件
重要: ハイライトに「Endless Wag」「ミシェル紹介」を固定
```

### Threads
```
投稿: 週3〜5本（テキスト + 写真1枚）
内容例:
・「今日のミシェル、5時に起こされた」
・「新しいタグの試作、3回失敗した」
・「佐原の散歩コース、ミシェルが絶対止まるポイントがある」
役割: 人柄を出す → ファン化 → Instagramフォローへ
収益: 直接収益なし。でもファンの「この人から買いたい」を作る
```

## ■ Endless Wag 販売導線の設計

```
Step 1: TikTok/Shortsでミシェル動画がバズる
        ↓
Step 2: 「この犬かわいい」→ プロフィール見る
        ↓
Step 3: プロフィールに「銚子の海で犬のグッズ作ってます ▼ Endless Wag」
        ↓
Step 4: Instagramに飛ぶ → リールで制作過程を見る
        ↓
Step 5: 「へーこんなの作ってるんだ」→ BASEリンクで購入
        ↓
Step 6: 購入者が自分の犬にタグつけて投稿 → UGC発生 → 新規流入
```

**ポイント: TikTokでは一切売り込まない。** 
売り込みはInstagramのプロフィールリンクだけ。
