## ■ キャラクター設計（最重要）

### ミシェルのキャラクター

```
食いしん坊 × 頑固 × 人好き
= 「ご飯のためなら何でもするけど、嫌なことは絶対やらない犬」
```

視聴者は「犬の動画」ではなく**「ミシェルの動画」を見に来る**状態を作る。
そのために投稿のたびにこのキャラクターを強化し続ける。

### プロフィール文（修正案）

```
食いしん坊で頑固なシュナ、ミシェル🐾
気まぐれだけど人好き
📍銚子
🔗 Endless Wag（犬のグッズ・タグ）→リンクへ
insta @endless_wag
```

## ■ コンテンツ設計

### 動画の基本フォーマット

| 項目 | 設定 |
|------|------|
| 尺 | 15〜30秒（完視聴率を上げる） |
| 向き | 縦・9:16 |
| 構成 | 仕掛け（3秒）→ ミシェルの反応（メイン）→ オチ（2秒） |
| 音 | 自然音そのまま（BGMなし推奨） |
| テキスト | 最初の1〜2秒にタイトルを出す |
| 頻度 | 毎日1本（継続が最優先） |

### タイトルの作り方（必ずこのルールで）

**入れる言葉：「末路」「〜すぎた」「〜なのに」「問題」「〜したら」**

| NG（伸びない） | OK（続きが見たくなる） |
|--------------|-------------------|
| 今日の散歩 | 初めての場所に連れてったミシェルの末路 |
| かわいいミシェル | 嫌なことは絶対やらない犬の問題点 |
| おやつをあげた | おやつのためなら何でもする犬、限界を試した |

## ■ コンテンツ3タイプ（この比率で投稿する）

### タイプA：食いしん坊（週3本）
アルゴリズムに乗りやすい。反応が早い。

**撮り方パターン①：おやつで従順になる**
```
① おやつを持って構える
② 普段言うこと聞かないのに全部従う
③ おやつをあげる瞬間で終わり
タイトル：「おやつのためなら何でもするミシェル」
尺：15〜20秒
```

**撮り方パターン②：気配を察知する**
```
① ミシェルが寝てる・くつろいでる
② ご飯の袋をガサッと触る
③ 瞬時にキッチンへ走ってくる
④ じっと見上げる顔で終わり
タイトル：「ご飯の気配を察知する速度がおかしい犬」
尺：15秒以内
```

**撮り方パターン③：食べてる顔のアップ**
```
① ご飯・おやつを食べてるミシェルの顔を正面から
② 必死な顔・幸せそうな顔
タイトル：「ご飯の時だけ本気になる犬の顔」
尺：10〜15秒
```

---

### タイプB：頑固（週2本）
笑いとシェアを生む。バズりやすい。

**撮り方パターン①：嫌なことを拒否する**
```
① お風呂・爪切りなど「嫌なもの」を見せる
② ミシェルが逃げる・固まる・無視する
③ どんなに呼んでも来ない
④ 「結局〇分かかった」テキストで終わり
タイトル：「嫌なことは絶対やらないミシェルの末路」
尺：20〜25秒
```

**撮り方パターン②：言うこと聞かない→おやつで秒解決**
```
① 「お座り」と何度言っても無視（声だけ）
② ミシェルがそっぽ向く
③ カット→おやつを出した瞬間に即座る
タイトル：「100回言っても無視する犬、おやつで0.1秒で座る」
尺：20〜25秒
```

---

### タイプC：人好き（週1本）
温かみがある。フォローされやすい。拡散される。

**撮り方パターン①：誰にでもなつく**
```
① 散歩中・外出先
② 知らない人が通る
③ ついていこうとするミシェル
④ リードで止められてまだ見てる顔
タイトル：「誰にでもついていこうとする犬が心配すぎる」
尺：20秒
```

**撮り方パターン②：訪問者への反応**
```
① 誰かが家に来る
② ミシェルが全力で迎えに行く
③ 知らない人なのに全力でお出迎え
タイトル：「初対面の人の方が好きなのかもしれない」
尺：20秒
```

## ■ TikTok収益化ロードマップ

### フォロワー1,000（目標：1〜2ヶ月）
- **解放：TikTok LIVE**
- ミシェルとのLIVEでギフトをもらえるようになる
- LIVEは週1〜2回、15〜30分
- 「ミシェルと夜のんびりLIVE」など気軽な設定でOK

### フォロワー5,000（目標：2〜4ヶ月）
- **解放：Series（有料コンテンツ）**
- 「ミシェルの特別動画」を有料で提供できる
- LIVEギフトが安定してくる

### フォロワー10,000（目標：4〜6ヶ月）
- **解放：クリエイターファンド**
- 再生数に応じて収益が発生（目安：10万再生で数百〜数千円）
- **企業からのPR案件オファーが来始める**
- ここでEndless Wagへの導線を本格化させる

### フォロワー50,000〜（目標：6ヶ月〜1年）
- ブランドコラボ・PR案件が選べるようになる
- Endless Wagのグッズが「この人のグッズ」として売れる
- 銚子×犬×アップサイクルの動画が影響力を持つ

## ■ Endless Wagへの導線設計

### フォロワー1,000まで（今の段階）
- プロフィールにBASEリンクを貼るだけ
- 動画にブランドの話は出さない
- **ミシェルのファンを作ることだけに集中**

### フォロワー1,000〜5,000
- 月1本だけ「タグを作った」「グッズを使ってるミシェル」動画を混ぜる
- 「このタグ、海で拾ったプラで作ったんです」と自然に話す
- 押し売りしない・ミシェルが主役のまま

### フォロワー5,000〜10,000
- ブランドストーリー動画を定期投稿
- 「Endless Wagの商品を買ったらミシェルが届けてくれた」など
- BASEへの流入が自然に起きる

### フォロワー10,000以上
- TikTok Shop（販売機能）を活用
- 動画からそのまま購入できる仕組みを作る
- 「ミシェルが使ってるタグを売ってます」が最強のPR

## ■ 撮影を楽にするコツ

- **段取りを決めてから撮る**（5分考えて2分撮る）
- **1回の撮影で3〜4パターン撮っておく**（ストック確保）
- **失敗もそのまま使う**（固まって動かないのも頑固キャラとして使える）
- **ミシェルの顔が見える角度**を優先（正面 or 斜め45度）
- **毎日同じ時間に撮る習慣を作る**（19時に投稿するなら17〜18時に撮る）
