# Endless Wag 第1弾｜絵コンテ（フレーム完全図解）
各カットで「画面に何が見えるか」を絵で示す

---

## SHOT 01｜砂とプラのクローズアップ（2秒）

**スマホの向き：縦持ち・地面向き・砂から5cm**
**自分：写らない**

```
┌─────────────────┐
│・・砂砂砂・・・・│  ← 砂粒が見える
│・・・砂・・・・・│
│  ●プラスチック  │  ← 画面中央にプラ
│・・・砂・・・・・│
│・・砂砂砂・・・・│
└─────────────────┘
スマホを砂に直接置いて撮る
```

## SHOT 08｜海を背景に話す（12秒）★最重要

**スマホの向き：縦持ち・目線の高さ**
**自分：顔〜胸まで写る（バストアップ）**

```
┌─────────────────┐
│  空・雲         │
│  海・水平線     │  ← 背景
│─────────────────│
│     顔          │  ← 画面中央やや上
│   肩・胸        │
└─────────────────┘

【光の向き】
太陽が自分の斜め前にある時間帯に撮る

    太陽☀
      ↘
    自分の顔（明るい）
      ←  スマホ（撮影者）

逆光（太陽が後ろ）はNG→顔が真っ暗になる
```

セリフ（そのまま話す）：
```
「銚子の海、来るたびにゴミが落ちてるんですよ。
 捨てようかなって思ったんですけど、
 なんかもったいなくて。
 犬のグッズ作ってるんで、
 これタグにできるんじゃないかなって思って」
```

## まとめ：自分の顔が出るのは1カットだけ

| カット | 何が映る |
|--------|---------|
| SHOT 01 | 砂とプラだけ |
| SHOT 03 | 海だけ |
| SHOT 04 | 自分の**足だけ** |
| SHOT 05 | プラだけ |
| SHOT 06 | 自分の**手だけ** |
| SHOT 07 | 袋だけ |
| **SHOT 08** | **自分の顔（バストアップ）** ← ここだけ |
| SHOT 09 | 自分の**手だけ** |
| SHOT 10 | 自分の**手だけ** |
| SHOT 11 | 自分の**手だけ** |
| SHOT 12 | 自分の**手だけ** |
| SHOT 13 | プラとタグだけ |
| SHOT 14 | 自分の**手と犬の首**だけ |
| SHOT 15 | **犬の顔だけ** |
| SHOT 16 | タグだけ |
| SHOT 17 | 自分の**後ろ姿と犬** |
| SHOT 18 | 海だけ |

**顔出しが嫌ならSHOT 08もナレーションに変えられる。**
その場合、海・プラ・手の映像の上に声だけ乗せる。
