## ■ なぜ329人で止まってるか（5つの原因）

| # | 原因 | 証拠 |
|---|------|------|
| 1 | **尺が長すぎた** | 50本が12秒超え → 完視聴率が低い → おすすめに乗らない |

1〜3は今日から直せる。でも4と5を直さないと1,000人に届かない。

## ■ 「フォローする理由」を作る

今の視聴者の心理：
```
動画を見る → 「かわいい犬だな」→ 次の動画にスワイプ → 終わり
```

フォローされるアカウントの心理：
```
動画を見る → 「この犬面白い」→ プロフィール見る
→ 「全部この犬の動画だ。他のも見たい」→ フォロー
```

**差は「この犬でしか見れないもの」があるかどうか。**

### ミシェルの武器: 「諦めない犬」

これを毎本のテロップに入れる。

```
❌ 「フード変えた日の犬の反応」→ どの犬でも成立する
❌ 「お友達ができました」→ どの犬でも成立する
❌ 「乗り方にクセがありすぎる犬」→ どの犬でも成立する

⭕ 「100回呼んでも来ない犬、おやつで0.5秒」→ ミシェルの執着
⭕ 「お手すればもらえると思ってる犬」→ ミシェルの諦めなさ
⭕ 「5分引っ張っても絶対離さない犬」→ ミシェルの執着
```

**テロップに「ミシェルの個性」が入ってるかどうか。**
これがフォロー率を決める。

## ■ 再起動プラン（8週間で1,000人）

### Week 1-2: 基盤を固める

**毎日のルーティン（20分）:**

| 時間 | やること | 所要時間 |
|------|---------|---------|
| 朝 | TikTokで犬動画3本見る。バズってるテロップをメモる | 3分 |
| 17〜18時 | 撮影（ミシェルの「執着」が出る瞬間を撮る）| 5分 |
| 18〜19時 | CapCut編集（12秒以内・テロップ・BGM） | 5分 |
| 19:00〜21:00 | 投稿（TikTok → 翌日YouTube Shorts） | 1分 |
| 寝る前 | コメント回り10件 | 5分 |

**動画のルール（絶対守る）:**
1. 12秒以内（例外なし）
2. 0秒目にテロップ
3. テロップに「ミシェルの個性」が入ってる
4. 19:00〜21:00に投稿
5. ハッシュタグ5個固定

### Week 3-4: データを見て型を絞る

14本出した時点で、再生数トップ3を分析する。

```
質問:
- トップ3に共通するテロップの型は？
- トップ3に共通する動画の構成は？
- トップ3に共通するミシェルのリアクションは？
```

→ 共通点が見つかったら、その型だけを繰り返す。

### Week 5-6: バズった型をシリーズ化

例: 「おやつで0.5秒」がバズった場合
- Vol.1: おやつの袋で0.5秒
- Vol.2: ご飯の皿で0.3秒
- Vol.3: チーズの包装で0.1秒（新記録）
- Vol.4: 何も持ってないのに来た

**シリーズ化 = 「次も見たい」= フォローする理由。**

### Week 7-8: 1,000人到達 → LIVE準備

フォロワー800〜900人になったら：
- LIVEの練習を1〜2回やる（非公開 or 少人数）
- LIVE用のネタを準備する
- 1,000人達成の瞬間をLIVEでやる → コンテンツになる

## ■ 動画の「型」を3つに絞る

57本いろいろ試した結果、ミシェルに合う型はこの3つ：

### 型A: 執着・諦めない系（週3本）← メイン
```
構造: 普通の状況 → ミシェルが異常に執着 → オチ
尺: 7〜10秒
テロップ例:
・「おやつの袋の音で0.5秒で来る犬」
・「おもちゃ取り上げても何度でも持ってくる犬」
・「お手すればもらえると思ってる犬」
・「5分引っ張っても絶対離さない犬」
・「飼い主がトイレ行くだけで追いかけてくる犬」
```

### 型B: チャレンジ・検証系（週2本）← 発見用
```
構造: 「〇〇したらどうなる？」→ 実験 → 結果
尺: 8〜12秒
テロップ例:
・「鼻ポチ何回で怒るか検証」
・「犬を完全無視したらどうなるか」
・「飼い主が倒れたら犬はどうする？」
・「飼い主が消えたら犬はどうする？」
・「犬の前でおやつ食べたらどうなるか」
```

### 型C: プロセス（週1本）← ファン化用
```
構造: Endless Wagの制作 × ミシェルが横にいる
尺: 8〜12秒
テロップ例:
・「犬に見守られながら仕事する人」
・「犬の名前入りタグ作ったら本人の反応」
・「海で拾ったキャップで犬のタグ作ってみた」
```

**この3つ以外は出さない。** 散歩動画、ベビーカー動画、お出かけ動画は封印。
理由: 「かわいい」けどフォローする理由にならない。
