# /清掃報告 コマンド定義

## 概要
清掃後に大樹不動産へ送るSlack報告文を生成する。

## 使い方
```
/清掃報告 [宿名] [日付] [ランドリー] [特記事項]
```

例：
```
/清掃報告 舫 4月5日 L×1 特記なし
/清掃報告 間 4月5日 L×2 2名セッティング・洗面台交換
/清掃報告 舫 4月6日 L×1 バイトあり
```

## 宿名の対応表
- 舫 / moyai / CTA → 「CTA」として出力
- 間 / awai → 「間（awai）」として出力
- 浬 / ri → 「浬（ri）」として出力

## 出力フォーマット

以下のフォーマットで出力する（Slackにそのままコピペできる形式）：

---
【{年月日}宿泊分の清掃報告：{施設コード}】

お世話になっております。

{施設コード} {日付}ご宿泊分の清掃作業を以下の通りご報告申し上げます。

ランドリー
・{ランドリー内容}

【特記事項】
・{特記事項}

ご確認よろしくお願いいたします
---

## 特記事項のルール
- 「特記なし」と入力されたら → 「特になし」と出力
- セッティング人数が含まれる場合 → 「〇名セッティングしております。」と出力
- バイトありの場合 → 特記事項には記載しない（内部管理用のみ）

## 出力後に追加表示する情報（内部管理用）
報告文の下に以下を表示する：

---
【内部メモ】
- 宿: {宿名}
- 日付: {日付}
- 清掃単価: {単価}円
- ランドリー: {袋数}袋 × ¥3,300 = {ランドリー売上}円
- 売上合計: {合計}円
- バイト: あり / なし
- 粗利: {粗利}円
---

## 単価設定
- 舫（CTA）: 清掃¥5,500
- 間（awai）: 清掃¥7,700
- 浬（ri）: 清掃¥7,700（暫定・確定後更新）
- 和泉屋: 清掃¥7,700
- ランドリー: ¥3,300/袋（実費¥1,000/袋）
- バイトコスト: 舫¥4,000 / 間・和泉屋¥5,000（ランドリー込み）
