# /清掃報告 コマンド定義

## 概要
清掃後に大樹不動産へ送るSlack報告文を生成する。
料金は大樹不動産との業務委託契約書（間awai）に準拠。

## 使い方
```
/清掃報告 [宿名] [日付] [ランドリーサイズ×袋数] [特記事項] [オプション:前日依頼]
```

例：
```
/清掃報告 舫 4月5日 L×1 特記なし
/清掃報告 間 4月5日 L×2 2名セッティング
/清掃報告 間 4月30日 L×1 特記なし          ← GW自動割増
/清掃報告 間 4月5日 L×1 特記なし 前日依頼   ← 前日依頼割増
/清掃報告 舫 4月6日 L×1 特記なし バイトあり
```

## 料金計算ルール（契約書準拠）

### 繁忙期（清掃料金・ランドリー料金とも1.5倍）
| 期間 | 日付 |
|------|------|
| GW | 4月29日〜5月5日 |
| お盆 | 8月10日〜8月20日 |
| 年末年始 | 12月25日〜1月7日 |

### 前日依頼
- 清掃料金 1.5倍（ランドリーは通常料金）

### キャンセル（当日）
- 清掃料金の100%を請求（ランドリーなし）

### ランドリー単価
| サイズ | 通常 | 繁忙期 |
|------|------|------|
| S（約12L） | ¥2,200 | ¥2,750 |
| M（約36L） | ¥2,750 | ¥3,300 |
| L（約71L） | ¥3,300 | ¥3,850 |

## 出力フォーマット（Slackにそのままコピペ）

```
【{年月日}宿泊分の清掃報告：{施設コード}】

お世話になっております。

{施設コード} {日付}ご宿泊分の清掃作業を以下の通りご報告申し上げます。

ランドリー
・{サイズ}バッグ分：{サイズ} × {袋数}

【特記事項】
・{特記事項}

ご確認よろしくお願いいたします
```

### 特記事項のルール
- 「特記なし」→「特になし」と出力
- セッティング人数あり →「〇名セッティングしております。」
- バイトあり → Slack文には記載しない（内部メモのみ）
- 繁忙期・前日依頼 → Slack文には記載しない（内部メモのみ）

---

## 内部メモ（Slack文の下に表示）

```
【内部メモ】
- 宿: {宿名}
- 日付: {日付}
- 区分: 通常 / 繁忙期GW / 繁忙期お盆 / 繁忙期年末年始 / 前日依頼
- 清掃単価: ¥{単価}（割増率: {倍率}）
- ランドリー: {サイズ}×{袋数} = ¥{ランドリー計}
- 売上合計: ¥{合計}
- バイト: あり / なし
- バイトコスト: ¥{コスト}
- 粗利: ¥{粗利}
```

---

## コスト設定（内部管理用）
- ランドリー実費: 約¥1,000/袋
- バイト（舫）: ¥2,500 + 交通費¥500 = ¥3,000（ランドリー担当時+¥1,000）
- バイト（間・和泉屋）: ¥4,000〜（ランドリー担当時+¥1,000）
